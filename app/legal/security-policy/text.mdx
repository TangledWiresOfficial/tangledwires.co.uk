## Security Policy

If you discover a security vulnerability in one of our services or codebases, please send as much detail as possible about your findings to [support@tangledwires.co.uk](mailto:support@tangledwires.co.uk) with "Responsible Disclosure" in the subject.

Make sure to include the following information:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact of the vulnerability
- Any possible mitigations you've identified

Unfortunately, we cannot provide rewards or bounties for vulnerability reports.
